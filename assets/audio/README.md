# 原创程序音效

这些短音效由本仓库 `tools/build_audio.py` 使用 Python 标准库的正弦波、包络、滤波噪声与简短音程原创合成，没有录音、下载素材、第三方采样或音色库。

```sh
python tools/build_audio.py
```

| 文件 | 用途 | 时长 |
|---|---|---:|
| `move.wav` | 轻步 | 0.13 秒 |
| `pickup.wav` | 水晶／物品拾取 | 0.52 秒 |
| `door.wav` | 开锁 | 0.42 秒 |
| `impact.wav` | 战斗撞击 | 0.30 秒 |
| `victory.wav` | 通关短乐句 | 1.65 秒 |
| `water.wav` | 阀门与流水 | 0.85 秒 |

全部为 44,100 Hz、16-bit PCM、单声道 WAV。音量保守，波形以平滑包络包住，首尾至少 5 毫秒精确静音；生成脚本检查 PCM 无削波、文件参数与最大 2 秒时长。`manifest.json` 记录实际峰值、RMS 和 SHA-256；`SHA256SUMS` 可用 `sha256sum -c SHA256SUMS` 校验。

这些是表现层音效，不参与战斗随机数或规则结算。接线时宜限制移动音效重叠并提供静音选项。当前机器可能没有可用音频设备；技术校验不等于在用户扬声器上的主观试听验收。

仓库当前未指定开源许可证，本说明不额外授予素材许可。
