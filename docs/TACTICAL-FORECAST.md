# 战术试算：看懂装备、技能与站位

V面对当前层已见敌人，比较已持装备在不用战斗技能与投入一次专注时的结果；这不是自动选择最强装备，更不是点击面板替玩家攻击。试算不改变装备、技能准备、生命、专注、行走、击杀进度或存档。当前实际准备状态另行显示，避免把候选当成已生效。

渡口守卫H额外比较挡板侧袭位置。必须把“该位置理论战损”和“当前是否有仅经过已清空地的安全路径”分开；路径不穿怪、门、资源、未知事件或楼梯。不可达时仍可解释站位原理，但不能称为现在可执行。没有位置奖励的敌人不伪造侧袭。

数字使用既有战斗规则，不另建近似公式：装备词条、策略、天赋、誓约、技能等级与当前生命条件一致。投入专注可能不省血，也可能因失去未准备技能的策略防御而更差；候选不得总标绿色或默认推荐。专注返还需按真实消费及容量上限，不能把理论溢出算收益。致死候选不许宣称战后回血或奖励能救回死亡。

学者的治疗是战外行动，不伪装成这次战斗的准备技能。没有专注时，技能候选即使显示理论计算也须明确不可投入。面板不新增怪物、装备或资源，不改变保存格式，也不保证一种构筑适合所有路线。
