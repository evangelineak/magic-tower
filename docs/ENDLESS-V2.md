# 无尽 v2：路线与运输的取舍

新局使用 v2，旧 v1 动作档继续按冻结的 v1 规则重放，不把旧动作放进新地图。经典模式仍独立。

- 双关隘庭院：重甲短路与两名轻装守卫路线。
- 断壁回廊：两道隔墙与不同入口，高攻高赏路线与低损低赏双哨路线。
- 右侧比较当前属性下两路剩余守卫的损失和金币，悬停每只敌人查看具体数值。该比较不是自动战斗，也不保证所点远处地格存在安全通路。
- 封存补给可以立即恢复20生命，也可放弃当下恢复，运到两层后的商人。途中到补给箱或商人旁可拆封，恢复生命但放弃奖励。
- 交付后独立三选一：攻击+4、防御+3或钥匙+2，每局一次。任务与消耗随动作重放，回访不刷新。
- 铁甲关尉、双刃矮兵、法袍守卫和宝库重盾使用不同扁平轮廓，不依赖字母或只换颜色。
- 本机历史榜标注规则版本。不同版本难度不同，不是联网公平竞技榜。

这是继续完善的独立无尽模式，不代表经典模式全部任务、装备、轮回与奇遇已经迁入；当前两类布局与四种敌人。全球榜尚无后端，也不会未经批准创建付费服务或上传玩家动作。

验证含旧版本重放、新版两条实际预算路线、门/守卫防旁路、跨层委托防重复、版本隔离存储与UI交互。原生试玩和真实浏览器存储验证分别记录，不能代替受限云浏览器中尚未完成的Godot Web引擎实玩。
