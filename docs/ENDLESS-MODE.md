# 无尽远征：可玩首版

经典魔塔顶部点击「无尽远征 · 15×15」或按F3进入。两种模式独立保存，不覆盖经典旅程。

## 怎么玩
- 实际楼层为15×15，保持64像素格子，用11×11视窗与全层概览浏览。走动自动跟随，右键拖动，空格回到角色。
- 相邻点击拾取、战斗、打开商店或技能选择；远处点击仅安全空地寻路。门与致死战斗保留确认。
- 每层先找入口附近训练与补给，再挑战必经关隘。旁支钥匙房和强敌宝库可自行取舍，守卫太强可以以后回来。
- 上下楼梯同坐标；拾取、战斗、购买和选择不会因回访刷新。没有经典八层终点，下一层按种子与层数生成。
- 暂停后可直接关闭；每次成功行动自动保存。保存未确认时画面不前进，按L核对已存旅程。不要把未确认的写入当作一定失败。
- 死亡或主动结束后进入本设备历史榜。它不上传服务器，不是全球榜，也不是可信联网竞技成绩。

## 首版边界
当前有一个主体结构与随机支路、两类敌人、限购商店及每层三选一成长。旧模式的全部任务、装备与轮回系统尚未迁入，不宣称已完成所有构想。数值安全界限为100万层，事件存档最多10万次动作，最后一条预留主动结算。长局仍需后续压缩优化。

原生采用独立文件、锁和原子替换；Web采用独立localStorage键与Web Locks。浏览器不支持Web Locks、容量不足、数据损坏或发生冲突时会停止写入并提示，不会静默清空旧档。未能证明安全的原生遗留锁也不会被自动抢占。

## 验证范围
四种子各40层使用真实游戏规则走通最低预算路线；另有几何与跨层契约、回访、商店、确认、存储和界面测试。最低预算并不保证随意省略成长或挑战强敌仍能通关。

原生实际试玩验证了第一层训练/补给、必经战斗、滚动地图、安全行走、第二层同坐标落点、返回再进入、读档恢复和本设备榜登记。真实Chrome验证了生产JS回调、Web Locks、localStorage与第二浏览上下文冲突。云浏览器的Godot Web引擎实玩仍未通过验证，不与这些测试混称。
