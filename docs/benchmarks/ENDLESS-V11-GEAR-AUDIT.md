## 平衡结论与限制

旧方案（ATK −2，首反击减 4，但无 DEF 代价）在同样合法策略下尾 25 层净损仅主 2 / 支 10，过度接近无伤，因此未发布并被拒绝。新增 DEF −1 后独立完整重跑，尾段为 20 / 43。不是将旧结果改标签复用。

功能和存档一致不等于平衡完善。此合法 balanced 策略中披肩显著压低持续损耗；镜显著增加损耗与药费。虽然核心定向测试另有镜跨过一击阈值、披肩导致额外轮次的局部反例，不能因此宣称两件装备全局等价或持续提供同等有效选择。

当前金币仍宽裕，披肩使部分尾段消费更少。装备提供真实规则取舍，但没有解决长期经济过剩或机械重复。新方案仍保留披肩省药优势，不能宣称已经充分平衡；也不要因全六局存活说成所有构筑均可通关。
