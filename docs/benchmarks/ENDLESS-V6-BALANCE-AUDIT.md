# v6 深层体验审计：安全预算变成永久无伤

2026-11-09；只读固定 v6 规则。可复现脚本：`tools/audit_endless_v6_balance.gd`；结果：`endless-v6-balance.json`。使用种子42、真实移动/领取/购买/技能、每条路线走满100层，并对全部日志重新重放。未注入角色属性、未改规则/协议、未模拟全球榜。这里是12种策略样例，不是最优策略证明或全种子统计。

```sh
godot --headless --path . --script tools/audit_endless_v6_balance.gd
```

## 公式解释

不额外强化时，第 f 层领取训练后攻击 `20+3f`、防御 `10+2f`。敌人攻击也每层+2，防御也每层+3，因此相对差值不变：

- 铁甲关尉 HP30、防御`9+3f`、攻击`14+2f`：每击11，3回合、2次反击×4，损伤8。
- 法袍守卫 HP30、防御`3+3f`、攻击`18+2f`：每击17，2回合、1次反击×8，损伤8。
- 支路两哨各 HP24、防御`3+3f`、攻击`13+2f`：各1次反击×3，总损伤6。
- 每层补给20，故无额外强化主路每层净增12HP，支路每层净增14HP。到100层没有线性必死，反而生命持续膨胀，直到3000上限。

角色额外永久属性会累积，敌人的上述差值却固定。免费技能每层防御+1，到8次足以压平全部普通敌人；额外攻击同样最终压到一击必杀。因此哪怕地图随机，后期战斗和路线选择仍可退化。

## 合法100层样例

策略含义：none只拿基础训练和即时补给；guard/power每层选择对应免费技能；armor/sword在能买时每层购买一次该物品；brace只启用无升级架盾。每层只有一个对应购买机会，未反复无限买。偶数层营地位于左侧而入口在右侧，部分决策需要先穿过路线；脚本真实走到营地，不隔空购买。

这些策略不绕路取钥匙，所有50/100层样本钥匙0。无消费主路比支路每100层多1150金币；基础主路100次击杀、支路200次。技能强化后主路也无伤，低收益支路失去其“低损伤换低赏”优势，成为更多战斗、较少金币的弱选择（其他未实现的任务目标不计）。

架盾免费，未训练就能挡住支路每个敌人的唯一3点反击，已经能从第一层起让整条支路无伤。故不能宣称所有战术仍有长期等价取舍。护符与凿甲钉在真实会受伤/无法破防的状态有用，但在上述无伤或一击状态，其减少承伤收益变成0；这不是证明它们在所有局面都无用，也不是证明某个商店选项永远全局最优。

## 回访样例

主路基础策略完成50层后，从51层入口**真正走回3层**，接近并击杀此前保留的宝库守卫，领取遗物。此分支也通过完整日志重放：

- 守卫预计及实际无伤；获得金币35、攻击+6、防御+4、生命+50。
- 共1144个合法动作（含返回路程和领取），没有使用传送或直接修改楼层。

因此回访仍有数值收益，但“强敌守好物、成长后回来”的局面过迟会变成免费拾取；1144步主要是时间成本。额外永久属性又强化后续无伤循环。宜保留早期适时回访的成就感，减少几十层后的空跑，不把旧层敌人暗中随玩家升级。

## 最重要的3点与v7建议

1. **永久成长压平敌人差值，8层左右已失去长期承伤压力。** v7应让不同敌人改变战斗解法，如有限次数反击护盾、先手条件、明确预告的破防需求或可消耗的防护，而非只按相同斜率增加属性。新增机制必须可预览、可重放、有明确反制；不能靠随机命中破坏可计算性，也不能为了制造压力突然让所有路线必死。
2. **架盾对两哨从开局即完全支配承伤，后期主路也被永久属性压平。** 可在v7提供至少一条“架盾有效”和另一条“破甲/先手更有效”的真实选择，让怪物反击次数、护盾等影响收益；验证零训练/普通上限/遗物超限多个构筑，不能只测默认角色。以50/100层路线仍存在机会成本为验收，不以怪物数量增加为验收。
3. **补给持续过剩、回访回报以永久数值为主，消费缺少后期用途。** 可以加入有限负重、运输与即用权衡、分支任务回报或有限资源开启的路线，并设计已清层快捷返回；快捷返回不跳未清敌人、不复制奖励。不要一刀削去基础安全路线的救济，再让玩家靠随机商店补命。

兼容要求：这些建议只写入新 v7 规则，旧 v1–v6原样重放；新旧榜按规则版本区分。本脚本继续固定v6，作为平衡对照，不能随着新默认版本“自动通过”。

### 分批边界

v7 的先制/蓄力等怪物行为只能增加局部战斗区别，**不能据此宣称已经根治永久属性与线性敌人成长的预算失衡**。本批保持已定 v7 数值，不临时加入真伤或改旧规则。建议 v8 单独设计并验算成长预算、永久奖励边际收益、补给供需和深层路线机会成本，再做相同50/100层对照与极端构筑验证。

数据口径提醒：主路 guard 第6层首次出现0伤，但之后仍有受伤楼层；**第8层起才持续0伤至100层**。`first_zero_loss_floor` 与 `sustained_zero_from` 不可混用。
