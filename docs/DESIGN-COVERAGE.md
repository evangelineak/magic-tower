# 原始构想核对表

这份表区分已经可玩的规则、正在实现的内容和仍然缺失的体验，避免把“有一个按钮”写成完整系统。具体测试证据在 VERIFICATION.md。

| 玩家期待 | 当前落点 | 仍有边界 |
| --- | --- | --- |
| 看似随机但有章法 | 首章五层三类整层骨架，独立三层远征；固定资源预算、种子复现、保守可解路线 | 不是无限地牢；资源类别和数量仍受作者约束，玩家错误选择不保证获胜 |

| 早看见好东西、以后回来 | 三层强敌宝库、双钥奖励笼、修桥后成长回打渡口；跨章楼梯保留旧图 | 最后首领击败后结束，本局结束前必须完成回访 |

## 接下来应优先验证的问题

1. 可选任务的奖励是否在得到后还有真正使用场景，而不只是收藏数加一？
2. 新装备是否至少有一类敌人更合适、一类敌人更差，预览能否让玩家看懂原因？
3. 新任务能否保留旧存档原貌，而不是刷新资源或追溯惩罚旧选择？
4. 新金币用途是否存在可理解的机会成本，是否被更便宜的药剂全面压过？
5. 增加章节是否增加不同决定，而不是只增加重复走路和总时长？

## v0.15 安全快旅已实现及边界

免费快旅只压缩当前“无战斗、无拾取、无消耗”的真实步行路径。锚点必须实际踏入或交互登记，不能用楼层见过来推断；旧档不能虚构到访历史。所有活怪（包括预计零伤）、未开门、未领资源均阻挡，水/工程桥按当前状态。楼梯要按实际跨层落点建有向边，修好的电梯才可加入对应边，不能用普通二维BFS穿过楼梯格冒充真实路径。

交通不得刷新专注、结算贷款、领奖、交任务或改变誓约。首章胜利必须先明确续章，最后胜利仍终止动作。免费快旅确实会降低旧电梯的后期便利优势和回N退约的摩擦，应公开承认这种体验调整；电梯早期用途与校准供能条件仍应保留。T 菜单只显示已登记地标，二次确认时重验路线。当前只开放于已续章且尚未最终胜利的旅程；不提供战斗或收益最优路线建议。
