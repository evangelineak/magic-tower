# 大地图与连续楼层：独立原型，尚未可玩

当前公开游戏仍为11×11地图、首章5层加远征3层。本目录的新模块不是已经完成的无限模式。

已准备：
- 实际矩形尺寸和边界查询；安全寻路能处理15×15或非正方形网格。
- 独立15×15确定性按层生成器，按种子与层数复现，楼梯与相邻层同坐标。
- 关键主路、随机支路、钥匙在门外的封闭奖励房，以及可暂时绕开、以后回访的守卫宝库。
- 验证门或守卫不能被旁路绕过；错误楼梯、缺钥匙、破坏房间封闭性会被拒绝。

尚未完成：实际大地图视窗和游戏模式入口、战斗数值与资源预算证明、装备/事件/任务分配、无限旅程结算、按需存储与Web协议，以及排名。

生成结果明确标记combat_budget_verified=false。几何可达不代表角色有足够血量、攻击或钥匙通关。现有schema19的11×11保存校验没有放宽。
