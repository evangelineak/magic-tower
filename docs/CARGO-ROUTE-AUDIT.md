# 货梯：钥匙时机与延迟生命的合法路线对照

执行：`godot --headless --path . --script tools/audit_cargo_routes.gd`。
结果：`docs/cargo-route-audit.jsonl`。Godot 4.6.3。

两局均seed1、原装护卫，沿生成器首章见证路线行走，只增加明确的开箱/发运和回访支路。没有技能、天赋、传承点、装备、购物或贷款；不注入HP、钥匙、地图或奖励。所有移动/开门/货梯操作均实际调用World并断言成功；唯一预期失败是钥匙不足时尝试L门。

## 对照结果

| 时点 | 1F花1钥立即开箱 | 免费发运、保留钥匙 |
|---|---:|---:|
|分歧前|412HP / 1钥|412HP / 1钥|
|处理原70HP箱后|482HP / 0钥|412HP / 1钥|
|2F走完、尚未上3F|509HP / 1钥|439HP / 2钥|
|回1F尝试双钥L箱|钥匙不足，原子拒绝|实际花2钥，获得60金币|
|K战前|699HP|629HP|
|K损血|533|533|
|K战后|166HP|96HP|

两组到1F货箱的接近/返回共同需要32步；立即开箱另有4步进入、拾取、退出，发运另有1次操作。这不是自动搬运或免费传送。

2F末回1F L门前需21步；立即开箱组未开门，回2F再21步，共42步。发运组开门并领取后，从箱内回2F为23步，往返行走44步，**另有开L门/拾取金币2步**。因此省钥带来的是可提前兑现的房间选择，不只是结尾多一个数字；但也不是毫无代价的奖励。两组均未将新增金币再投入购物，避免混入额外变量。

**立即开箱组并非永远拿不到L。** 它可以继续探索、找到下一把钥匙后再回访；本实验说明的是发运让这个选择提前出现，而不是永久剥夺另一条路线。

## 延迟兑现条件

本种子的货物发往5F王座。K刚胜利时还不能领取，必须明确选择继续远征，解除第一章胜利暂停。继续远征单独赠送的固定120HP不是货物奖励：

- 发运路线K后96HP。
- 明确继续远征：96 → 216HP，来自章节补给120HP。
- 从6F入口沿已清路线 `UDLLLLLLULUUUUUL` 实际16步回5F(1,3)，没有战斗或拾取额外资源。
- 再执行1次领取操作：216 → 286HP，只有这70HP来自原货箱。

延迟70HP使首章末安全余量从166下降到96。这个种子两条路线都能通，但发运不是无条件更强；早期血量紧张或不打算继续远征的玩家，可以合理选择立即开箱。实验是两条具体合法路线，不是全种子或最优路径证明。
