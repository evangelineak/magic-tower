# v21：固定候选天赋与本机轮回

状态：设计/实现中。线上已验证版本为 v20；本页不是已实现声明。

## 本批目标

让不同局真正形成不同构筑，并让一次失败或主动退役保留探索所得；不是增加无上限永久攻防，也不靠反复死亡刷余额。

- 击杀 3 / 8 / 15 解锁三轮天赋。九张目录由版本与种子确定洗牌，分为三组每组三张；候选固定，可延后选，确认后不可改选，无付费重抽。
- 三英雄与传承在新局准备中分别选择；取消选择不覆盖旧旅程。每局最多一件传承，可不携带。
- 跨局首次结算到达 3 / 8 / 15 / 30 / 50 层的里程碑各得一点；死亡与主动退役同等，终身五点。三项永久横向解锁成本 1 / 2 / 2 点。旧版本不追补奖励。
- 解锁是明确的永久付点操作，不是普通选卡；已解锁不重复收费。开始新局另行原子确认。未结算的结束旅程先结算再允许新局。

## 原子性

只用已有 native 文件或 Web key/锁，不另写 profile。envelope2 包含旧六字段、严格 profile 与当前结算 receipt；世界 DTO 仍为版本/模式/种子/事件四字段。初始 hero_*、legacy_* 两条规范事件，world 回放不读当前档案。

finish 同一 CAS 提交 finished、排名、首次里程碑和 receipt。余额由已领里程碑数减固定目录解锁总成本计算。重试、重读、top10淘汰、解锁后再读不能重复领或丢失已确认本局收益。旧 envelope 只读不写，首次成功写才升级；失败、quota、冲突不能覆盖原字节。未来未知版本拒绝，不擅自清档。

## 验收

每个角色和组合的战斗预报/实际事件一致，固定候选与回放一致，封顶不白花资源，拒战/取消/失败无副作用。独立 native/Node/真实Chrome验证双上下文结算与解锁竞争、丢回执重试、旧存档迁移、余额守恒及真实旅程结算。仍须原生实际试玩，不能把脚本数量视为乐趣与平衡证明。

本机档案仍可被设备主人修改，不是可信全球榜；无服务器、账户、收费或玩家数据上传。
