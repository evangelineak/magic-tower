### Session 接线之后的交付顺序

1. 完成候选状态提交、真实双窗口和导出包验收，保持网页稳定版独立。
2. 以同一事务提交终局 World、跨局档案和唯一收据；验证重复确认、丢失响应、重开窗口和存储失败，不把安全拒战视为死亡。
3. 再开放明确自愿的风险模式、真正 HP=0 终止和轮回选择。终局成功落盘后才能清空本局撤销；旧档或无身份测试局不得领奖。
4. 首次探索里程碑解锁有限的构筑选择，防止反复自杀刷取成为必需；抽选结果固定且可说明。具体天赋效果与经济平衡另做实玩验证。
