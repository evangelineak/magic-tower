# 当前整体体验核对（v19线上；v20开发版验收中）

这是现状与待办，不是已完成承诺清单。用户要的是一套丰富、能反复玩的魔塔，而非把不同系统分散在两个入口、靠按钮数量显得丰富。

| 用户方向 | 当前无尽模式 | 真实缺口 |
| --- | --- | --- |
| 大地图、有约束的随机、门后有价值 | 15×15、11×11视窗、七类骨架、楼梯配对、主单/支双守卫、真封区门；四类可预览宝库 | 骨架仍有限，远非大规模房间组合；深层机制/环境转变不足 |
| 推理、奇遇、彩蛋、回访遗憾 | 种子遭遇、跨层运输、一次信使线索、战斗订单、铭文与双臂桥、保留不可领宝物；v19最多两次早期推石空间事件已实现并原生实玩 | 多数选择仍在营地菜单；信使与推石是有限早期事件，不解决深层重复；回访有真实长途步行成本。v19已公开部署，BUILD身份已核验 |
| 多英雄、装备、技能、天赋、轮回 | v20开发版增加三英雄身份与有限专注主动技能，保留三战术、训练/遗物、一槽装备和两种道具 | v20尚待公开部署确认；天赋抽选、天赋册、跨局传承与死亡轮回仍未整合，不能把经典完整英雄体系冒充已移植 |
| 贷款与经济决策 | 购物、押金订单、钥匙机会成本 | 贷款仅经典模式；v18虽削减固定现金箱，免费药/工具仍可替代支出，深层财富过剩未解决 |
| 水域和多种环境 | 有沟渠布局外观、经典模式有水域分支 | 无尽沟渠不是功能性水域；没有丰富环境规则 |
| 强视觉辨识、统一风格、战斗画面 | 原创平面英雄/敌人/交互图形、差异宝库、战斗结算表现 | 不是完整逐击战斗动画；多怪/多英雄职业身份与整套画面仍需扩展，不能以图标数量当视觉完成 |
| 排名、网页随时玩 | 原主页公开GitHub Pages；本机历史榜；原生实玩与真实浏览器持久化通过 | 无全球验算后端；云Chrome的Godot Web引擎实玩受WebGL限制，未验证，不能以存储harness冒充 |

## 下一步体验优先级

1. 推石已做到地图上的站位、推动、插槽开门和可复位试错；原生验证了实战、改选与重启恢复。下一步观察实际使用与绕路价值，并补受环境限制尚未完成的Godot网页实玩，而不是把这两次早期事件视为整个无尽循环已经丰富。
2. 保持奖励有差异与代价。任何新增事件都应评估对既有钥匙、宝库和深层消耗的影响，不继续无条件堆现金或永久属性。
3. 再解决入口与构筑割裂。主页目前先进入经典，F3才能到无尽；玩家可能误以为新功能没更新。v20已把三种英雄身份和有限主动技能带入无尽，但天赋与轮回仍待独立设计；需清楚呈现模式区别，不能称完整经典构筑已经整合。
4. 全球榜需账户、公开信息和费用边界的明确选择，可信回放算分与滥用限制；不应阻塞本地可玩改进，也不能擅自接收费服务。

每批仍须实际试玩：新玩家是否知道目标、操作是否直观、选择后是否有清晰反馈、是否值得再来，而不只检查脚本计数。

本批证据与边界见 [v19说明](ENDLESS-V19.md)：原生实玩已验，真实Chrome仅持久化harness已验；两者不等于Godot网页引擎实玩，原主页公开BUILD已核验：源码1326d140，部署5096f24a。

v20开发验收见 [英雄说明](ENDLESS-V20.md)：独立24条真实100层对照与协议测试已完成，原生三英雄实玩已验证取消新局不覆盖v19旧档、三种技能实际效果、学者重启恢复与自愿致死结算；全量最终验收仍在运行，须另行登记。最后确认的公开版本仍为上述v19，不能把开发源码功能提前说成已上线。
