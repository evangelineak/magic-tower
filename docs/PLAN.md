# 苍穹之钥：设计与实施计划

## 核心取舍

先做完整小循环，而非空壳大世界。第一版 3 层，约 10–20 分钟；以经典魔塔的数值规划、探路与回溯为核心。原创低多边形塔楼作为氛围主视觉，棋盘使用清晰的 2D 符号，以可读性优先，不假称全 3D 游戏。

美术方向：深海蓝、青绿魔法光、黄铜金。固定 1280×800 逻辑画布，窗口缩放保持布局。战斗前透明展示损血，无随机暴击，无氪金。

## v0.1 已实施

- 3 张 11×11 手工地图，三类敌人、最终 Boss。
- 先手战斗公式、无法破防与致死保护。
- 钥匙/门、攻击/防御宝石、药水、金币评分。
- 双向楼梯、楼层状态保持、地图探索。
- 敌人悬停预览、手册、胜利画面。
- 本地 JSON 存档、坏存档保护、100 步会话内撤销。
- 原创 Blender 源场景、可复现脚本、PNG 和 GLB。
- 纯规则自动化测试与完整通关验证。

## 后续里程碑（尚未实施）

1. **可玩性打磨**：邀请真实试玩，收集路线/失败原因；建立至少 3 条可行路线，对攻击/防御选择做平衡。增加音效、战斗反馈、开场教程、中文本地化。验收：新玩家不看文档也能完成第一层。
2. **数据驱动内容**：地图/敌人独立资源、关卡编辑工具、可验证存档迁移、10 层章节、商店、事件。验收：新增楼层无需修改 UI 代码。
3. **发布工程**：Windows/Linux/macOS 导出预设与自动构建、版本化发布、手柄支持、设置与无障碍。验收：干净机器解压即可玩，存档迁移与回滚通过。
4. **可选 3D 模式**：将当前 GLB 美术语言扩展到格子、敌人与角色。前提：二维版规则和平衡先成立，不因渲染拖慢核心可玩性。

## 风险与边界

- 当前地图偏教学、宽容，不代表最终高难度平衡。
- 当前只有一个本地存档槽；R 两次会覆盖自动存档。
- UI 和规则已分离，但数据仍内置在 world.gd，避免为原型提前过度架构。
- 不使用现有商业魔塔素材/商标，不拷贝其他游戏关卡。
- 仓库按用户要求公开；公开不等于授予开源许可。许可证由作者后续选择。
