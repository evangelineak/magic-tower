# Endless v16: the keyed, twin-arm bridge

New journeys use v16; v1–v15 logs retain their original rules. Publication is separately gated on final tests, exact-commit CI and the original homepage BUILD identity.

## A spatial decision, not another permanent stat button

A seeded optional courtyard on some odd-numbered floors contains one keyed winch. Spend one existing key to lower one arm and mechanically lock the other. No payment is necessary to finish the ordinary floor. Choosing neither is a valid way to keep the key for the existing treasure door.

The short arm bypasses the first of two alternate-route guards, but the second remains mandatory. The skipped enemy stays in the world and can be fought later for its reward. This is explicitly a new family's paid-bypass contract, not a claim that both old alternate guards are still mandatory. The ordinary single-guard route remains available. No bridge choice permits a zero-combat exit or a side entrance into the existing keyed or guardian vaults.

The treasure arm opens a separate guarded tool cache containing one ward and one spike. It grants no bonus gold. Full inventory keeps the whole cache in place rather than losing part of the reward. The player can return after growing stronger or freeing inventory space. Opening the bridge is not an instruction to attack automatically.

The comparison must show current combat costs, the skipped enemy's bounty, the guarded tools and the irreversible loss of the other arm. All forecasts use the current build and consumables. A distant click remains safe navigation only; an adjacent winch interaction opens the comparison; only explicit confirmation spends the key. Bridge walking itself is free.
