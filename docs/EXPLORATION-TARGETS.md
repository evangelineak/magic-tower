# 回访目标：让已有决定留在地图上

本批把已有资源和人物分支变成可钉选目标，不增加额外奖励、任务货币或自动路线。J 打开回访目标，详细旧日志仍可切换；目标覆盖封箱货梯、三层宝库、样本用途和米拉去向。卡片回答去哪、为什么、还缺什么。钉选后右栏持续提示，目标在当前已见楼层才显示定位角标。

目标每次从当前真实世界重新推导，读取不行动、不领奖、不改存档。跨层只给已获知的楼层信息，不展示未见楼层的坐标；未完成的互斥选择不能冒充两个都能得到。钉选属于界面状态，不跨读档或新局保存；完成、撤销和读档后不得留下过期提示。不会根据当前战力擅自推荐“必胜”或替玩家穿过怪物和门。

同批修正五层校准台消失后货箱标记跟着消失的问题，并用与地图一致的独立 Blender 模型重渲染门卫、渡口守卫和监牢守卫战斗肖像。风险模式的致死说明须区分“完整击败所需承伤”与实际死亡事件停止，不能宣称风险战斗被安全模式规则一律阻止。

以上为批次范围；完成测试和发布情况以 VERIFICATION.md 最新记录及网页 BUILD.txt 为准。战术试算、可推动的导流石阵尚未实施，不能作为已有玩法宣传。
