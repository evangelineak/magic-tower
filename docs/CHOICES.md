# v0.3：先验证选择，而不是堆内容

这是在原三层原型上的第一轮可玩纵切，不代表全部设计落地。

## 本轮规则

五层固定地图。第三层可见宝库由高防御巨像守卫；先探索四、五层再回访。最终首领在五层，击败后结算，因此要拿宝库应在决战前回去。

第二层唯一机关芯可用于一/三层电梯、四层工坊 +8 防御，或一层商人出售 35 金币。没有机关芯也能沿普通楼梯走完主线。电梯使回访快，也开启一个后续秘密；工坊直接减少损血；出售缓解现金压力。

一层商人卖 60 金币的破甲武器（+12 攻击）。可借一次 40，手续费 2；首次进入四层与五层各对剩余本金计 10% 利息、向上取整，最多两次。全程不还合计50。随时打开账本提前偿还可用金币。计息节点先弹确认，取消不扣钱。到期债务冻结，后续金币先偿债。无复利，无现实时间/行走步数利息，无真实货币。

四层碑文与五层静默钟形成线索秘密，奖励不是主线必需。选择工坊或出售会放弃这条秘密，但仍可通关。

## 保留边界

- 战斗仍为确定性公式，有短暂斩击与损血反馈，尚非独立战斗场景。
- 尚无随机生成、英雄选择、天赋树、水闸、任务链。需要在本轮路线、经济和回访体验稳定后分批实施。
- 新旧存档分开，v1 不自动迁移。新存档版本2保存全部贷款、机关和秘密状态；撤销不能只撤代价不撤收益。
- 数值为试验参数，不宣称已完成多人平衡测试。
