# v20：先把三英雄带进无尽

状态：本地验收完成（110 套 Godot、Node、独立门禁及三英雄原生实玩）；正在按原主页发布流程验证，具体线上版本以 BUILD.txt 为准。以下记录本批原设计和验收范围。

## 玩家流程

- 新局先选守护者、游侠或学者，显示真实主动技能与专注代价；预览不覆盖旧旅程，最终开始才原子保存新局。
- 英雄身份与营地战术分开。换战术不变职业外观，B 面板统一查看身份、技能和战术。
- 2 点起始专注，上限 3；主动技能有限使用。仅第一次达到新的四层里程碑恢复一点，往返楼梯不能刷，满时溢出丢失。
- 战斗预备技能可以撤销，只有实际战斗消耗；拒战、取消确认、存储写失败都不能损失资源。学者战外治疗，满血不消耗。
- 三职业不直接复制经典模式的高生命数值；以无尽 180 生命与固定战斗顺序重新核算。

## 边界

本批不假装已有无尽轮回或天赋抽选；下一批接局内种子技能/天赋选择和原子跨局结算。旧规则 1–19 冻结，新开局才应用 v20。经典存档与用户旅程不删除。

本设备历史榜不是全球榜。对本地文件的校验只保护正常操作与损坏边界，不提供对恶意客户端的可信排名。

## 发布前必须完成

- 每英雄实际新局、技能预备/撤销/实战、满血拒绝、死亡与重启恢复。
- 逐事件独立战斗 oracle 覆盖先制、蓄力、反伤、回血祭司、震击/寂静、装备/道具/战术组合及临界血量。
- 新最高层专注恢复不可重复、封顶溢出不追补、技能资源和地图/确认同步。
- 不同英雄和策略的 50/100 层合法路线比较，不能只把正确计算误当平衡已达成。
- Native/Web 初始快照 CAS、丢失回执幂等、冲突/容量/失败不覆盖旧局；旧版本读取回归。
- 原生实玩与真实浏览器存储分开记录，未验证 Godot 网页引擎时明确保留限制。
