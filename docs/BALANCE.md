# v0.6：让选择真正有代价

## 为什么不是继续堆内容

只读模拟发现旧版41个种子的无技能/无借贷路线，结束生命689–850、平均782；中途最低生命几乎不低于初始360。主要损血集中在最终首领。决战前金币约238–256，而唯一永久商品仅60，最终首领又给100（本局已经结束，不能再消费）。因此“有贷款按钮”不等于有金融取舍。

## 本轮采用

- 初始生命280，普通药水70。
- 伏击者95HP / 42ATK / 14DEF；荆棘守卫90HP / 35ATK / 12DEF，把一部分危险移到中途。
- 护卫技能按总伤害35%减免，强化45%；减免量向下取整，再应用不屈20，零伤没有最低保底。学者仍稳定治疗80/100，游侠可通过破甲改变回合数。避免“护卫固定挡30被学者固定回80严格压过”。
- 每层一把金钥匙，五层共五把。第1/3/4层各有两钥匙奖励笼，总需六把：金币60、攻击5、生命140与1专注。普通捷径门也消耗同一资源。基线主线不需要这些笼房，选择不是必填税。
- 门前确认明确花1或2钥匙，取消不耗资源；笼房保持可见，可以后回来。

## 验证依据及边界

在钥匙笼房改动前，280/70+中途敌人加强的候选方案已对0..200共201个种子模拟并用候选World逐步重放：全部有解，零回退，结束生命147–426、平均297.6。敌人伤害更分散，但最终首领仍占大头。这是工程与数值证据，不替代真人试玩；最终笼房版本已再次跑当前仓库的200种子真实重放：全部通关，0回退，最终HP141–426；不使用钥匙或奖励笼。seed0保守主线剩212HP，317步。

没有因为金币过剩就无脑添加无限药水或专注出售，那会进一步消除风险；也没有硬加信息收费，因为当时的公开地图/图鉴限制了情报价值。

走私者的一次交换可补钥匙，也可卖钥匙换金币。一个可推理的取舍是：卖1钥匙并跳过金币笼，与买2钥匙拿齐所有笼，并非同一收益；多出的钥匙是否值得15金币差价取决于捷径计划。保留这一差异，不把“收齐”设为唯一正确答案。所有交易和宝箱均一次性，不存在循环套利。
