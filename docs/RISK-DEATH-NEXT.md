# 明确风险死亡：实现设计与约束

风险战斗已接入开发分支的完整World与原子终局事务。安全默认仍拒绝预计致死战斗；新局须明确选择risk，普通撞怪仍先确认。以下记录设计约束，实际验收见VERIFICATION.md。

## 明确确认与原子终态

风险模式也不因普通撞怪自动赴死。明确确认绑定完整开战快照、方向及敌人；任何装备、HP、位置改变后必须重新确认。候选内执行真实时间线直到致死，HP=0、ended_reason=death，仍停原位，不删怪、不发金币/击杀/任务进度、不触发战后治疗。已投入的战技按开战消耗专注并清除armed，确认页说明。与档案和defeat收据一次事务提交，失败仍显示原活人状态；成功才清Undo。不能用finish_run(defeat)把任意活人直接设死。

## 战斗时间线

现公式是整场聚合伤害，不能把总伤截到HP便称真实死亡轮。独立纯时间线实现按先制、诱敌反击、接触荆棘、实际攻击及反击事件累计。Brace与Unbroken采用累计净伤前缀之差，使每个存活战斗最终损伤与旧公式完全等价。

荆棘新增明确时序：接触先承受荆棘，活着才能完成该次攻击。因此风险中最后一击前可能被荆棘杀死，敌不被击杀。旧公式没有死亡顺序，此规则须在风险说明和怪物提示明示，不能冒称旧行为；safe仍拒战不变。

目前敌HP最高720，合法最低伤害1，保守事件数低于4324；硬上限为8192。见fatal立即停，超限返回错误、禁止确认结算，不能截断事件伪造死亡。存档只保最小death_record，读档重算验证，不信任客户端提交的回合数/伤害；动画仅播放真实发生前缀，较长过程可明确快速战报或跳过，不伪造回合。

## 验证

先制未出手死、诱敌死、荆棘接触死、锤双反击/第三击重击死；重盾首击减免、弩前三击、誓约与侧翼先制豁免；Brace前缀取整、Unbroken跨事件。所有存活装备/敌人/技能组合需与旧预览总伤一致。schema新版本仅允许risk/death/HP0有一致可重算记录，safe HP0和旧档死亡均拒绝。终局失败不损资源，重试只一份defeat收据，旧checkpoint不得复活同身份。
