# 第二章设计与验收约定

本章的目的不是把五层复制成八层，而是让首章留下的金币、钥匙和构筑继续产生选择。最终验收结果另见 VERIFICATION.md。

## 章节边界

第五层首领倒下仍是一次有效胜利。玩家可以保留这次胜利，或者主动继续三层远征。只有主动继续才生成并保存新章、领取一次120生命行军补给，并开放跨章楼梯。旧档不自动续章、不重抽原地图、不重置英雄与经济。所有首次进入楼层的专注恢复照旧；六至八层不增加贷款利息。

## 金币的机会成本

营地不是无限回血机：药剂70金币立即恢复140生命，整段远征共两份；专注55金币立即恢复1点，共两份，已满时不能购买。工程80金币一次开通三层桥。金币也可用于一次路线工程，避免一段可预见的战损，但绕开敌人时不凭空领取金币和击杀进度。玩家仍可选择之后回去交战。

药剂提供普适生存能力，专注的价值由英雄和天赋决定，工程价值由当前装备及敌人预览决定。三者不应有始终严格优于其他选项的一项。旧校准账券的50金币因此可以跨章使用；选择80生命加钥匙的玩家则保留不同资源，不能同时领两份。

## 公平性边界

- 新章的地图验证不替代原五层验证，不消费其随机序列。
- 无购物、无工程、无技能的保守路线必须能走通。新章起始生命证明使用121（首章最少存活1加一次120），不能把200种子抽样的最低余血10当成所有种子的下界。
- 该证明依赖首章保守路线获得的基础攻击和防御；玩家提前打首领、选择不利装备或绕过成长，不能据此推断所有构筑都可零思考通过。
- 存档保存地图、库存、工程和章节状态。加载不得重复补给、重新随机或恢复已消费库存；撤销恢复收益和成本的完整快照。
- 新章胜利与首章胜利有清楚的界面区分，继续按钮不得被重复点击领补给。

## 验收重点

完整的首章至新章路线重放、旧档迁移、继续动作原子性、跨章回访、贷款不再计息、购买失败无扣款、库存耗尽、工程开关与撤销、第二章最终首领、中文显示与真实键鼠游玩。Windows交叉导出不能写成Windows运行验收。

## 渡口的不同收益

渡口守卫180生命、62攻击、30防御，先制攻击，奖励60金币。三个渡口合计180金币和3次击杀，工程只开放路线，不提前发这些奖励。其预览沿用现有先制规则，不添加暗骰。付80金币修桥可先保留生命、以后成长再回来拿守卫奖励；免费打过去则付战损换金币，可能资助之后的药剂。药剂库存有限，金币够多也不能无限买命。
