# v22 实施边界：双池洪闸与战斗反馈

状态：开发中，尚未公开部署；最后核验线上仍 v21。

本批不增加装备词缀、属性体系、奖励菜单或收费后台。优先让水成为真实空间：北池与南池交替可通行，三处永久干地阀门免费可逆，干岛连接两池。主路始终有一个守卫；支路有两个，保留可预览的损耗、赏金及击杀进度取舍。岛上安置原有守卫封区遗物，给成长后的回访目的，不额外凭空发资源。原钥匙宝库仍必须经过门，不能从岸边绕进。

首个水庭在种子决定的4或6层，之后按8层窗口放置一个偶层，避免连续或与旧推石/桥冲突。两种实际空间变体。楼梯配对坐标、入口营地与课程可达必须保留。水位不能淹到玩家、怪物或奖励；免费操作只能在永久干地阀门旁发生，不按时间/随机数暗中改变。安全自动走路绝不拨闸、开门、拾取或战斗，积水会立即终止路径。

旧1–21规则冻结，新22重放水位动作；沿用21战斗、英雄、种子天赋与同设备轮回资料。存储仅扩大明确支持的版本，schema/key不变，23拒绝。特别验证21→22同里程碑不重奖，解锁所有权仍强制检查。

战斗改进是明确标注的英雄差异示意和实际贡献数字，不伪装成逐击回放。界面不再结算战斗，不制造未发生的英雄出手，点击跳过不透传到地图。

验收要包含完整空间状态图/双向回访/无零战通路/门奖励隔离、实际合法旅程与跨版本存储、原生鼠标拨闸和水域可读性。Chrome存储测试不等于Godot WebGL实玩；后者在当前云图形环境仍未验证。
