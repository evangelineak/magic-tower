# 封箱货梯：资源时机与回访

本批已实现并通过本地验证，公开网页是否包含以BUILD.txt为准。不是新货币、付费抽取或增加免费奖励总量。

第一层原一钥房70生命补给改为明确封箱：可以正常付钥开门领取，也可以从外部发运，把同一箱补给送到明确标注的高层目的地。发运保留钥匙，但补给推迟；玩家要比较当前生存与其他钥匙房的用途。发运与领取不能两头获利，发运后空门不再诱导付钥。

固定种子给出两个目的地之一，标签事先明示，不猜隐形概率：
- 三层星徽货箱受巨像V守护，必须成长后击败V才可领取；不能绕箱进入宝库。
- 五层王冠货箱在校准台旁，王冠封印需击败K且明确继续远征后才可领取。与校准谜题及其奖励独立，不会替代或覆盖原资源。

第一次读签即可知道目的楼层、守卫条件和原补给内容。选择前预览，确认才消耗行动；不做走到就自动替玩家发运。旧旅程不开新箱、不刷新地图。所有主线种子证明不依赖此箱；门不可绕、楼梯同坐标、安全自动寻路不消费资源的原则必须保留。

## 同批战斗反馈

修正游侠未用技能仍显示精准射击、取消先制仍表现受伤、把接触荆棘画成攻击后反伤三种误导。仍是2.4秒可跳示意，不伪称逐击真实动画。战后显示存档真正提交后的生命、实际专注返还（含封顶）、技能消耗、金币入袋和抵债，不拿理论返还冒充实际收益。失败和重读不播放奖励，重试只播一次。

## 平衡决策

不因终局HP高就削弱合法构筑。合法路线审查显示3层巨像仍有攻击阈值，5层未打K时回访仍打不过；7层囚守对原装学者已经容易，不能归咎新增传承点。先让代价/回报看得明白，保留有限资源组合的乐趣；后续敌人应重视公开阈值和空间取舍，而非惩罚玩家懂得搭配。
