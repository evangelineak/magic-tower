# 传承配点：有限成长，不刷死亡

本文件记录已实现的本批规则；源码验证与已发布网页不是同一件事，具体发布与验收状态见VERIFICATION.md。

## 玩家决策

首次实际结算到达3、5、8层，各解锁1点每局可配置容量，总共3点。安全退役、胜利与风险死亡使用相同的已到达楼层标准。重复相同里程碑没有点数，不出售点数，不需要故意死亡。已有档案的真实里程碑自动构成新局容量，不另发收据。

新局在原有策略选择页面一并分配，然后一次确认。可全部不投、可保留余点；下局免费重配，本局开始后不可重配。选择“原装策略”只表示无策略修正，完全原规则需要同时配点0/0。

- 研习0–2点：每点技能等级+2。适用于英雄主动技能，所有来源合计仍以20级为上限。显示原始合计、有效等级及溢出，不把无效投入宣传成收益。
- 应急专注0–2点：每点携带一份本局一次性专注补给。非战斗且专注未满时主动使用，+1专注，消耗一份与一个行动。满专注拒绝且不消耗；未用的补给不能兑换永久奖励。
- 总投入不超过出生容量；三点无法同时点满两栏。短线补给与长期技能效率应形成选择，而非隐藏必选答案。

## 一致性边界

schema17新增`legacy_points={version,capacity,study,reserve}`及`legacy_reserves`。出生容量固定，策略选择事务同时锁定策略、配点与初始补给。普通保存不能改配点；正常撤销可恢复实际消耗的补给，不能改出生预算或重新分配。相同nonce重试必须核对策略和配点，不允许同一请求身份换方案。

旧16及更早旅程迁移成version0、零容量和零配点，不追溯中途加成；旧待选策略仍可正常选择但不补点。档案本身没有可刷的可消费余额，原有收据去重规则不变。

## 必须诚实保留的平衡风险

逆境蓄能与专注训练同属第二册，不能同时拥有；研习策略与深度导流同属开局单选，也不能同时拥有。此前用这些互斥项叠加估计最高收益是不成立的。

新增研习可能让“逆境+研习策略+深度专注装备”达到20级治疗130；“逆境+导流+深度专注装备”在研习两点时达到16级治疗110。高收益仍需先活过战斗、有限敌人实际死亡，不能无限重杀，但40点损伤触发阈值可能鼓励繁琐的逐战卸盾。保留组合并进行真实合法路线比较，不能把单元测试通过当成所有构筑平衡。

## 可复现的路线观察

`tools/audit_legacy_points_routes.gd`先用原装学者实际打完8层并结算，取得真实三点资格，再比较18条三英雄普通路线和6条高回焦学者路线。结果见`LEGACY-POINTS-ROUTE-AUDIT.md`与原始JSONL。储备前期保障与研习长期效率确有不同收益；高回焦学者强势，在seed23合法导流+逆境组合中，零点终局2139HP、研习2/储备1达到2719HP。点数不是唯一来源，原组合和不封顶治疗已经很强。本批保留可解释的组合，不宣称全面平衡，也不为抹平构筑差异立即削弱。

准备页在英雄选择之前出现，因此同屏预览三个英雄的真实技能效果，而不是只给默认护卫的说明。数值由与实际战斗相同的技能函数产生：例研习1、无其他加成时，护卫减伤40%、游侠无视12防御、学者治疗90生命。玩家不必先锁配点再猜另一个英雄会受益多少。
