# 局内天赋册：前两层的构筑期待

本批开发内容，尚未混入已经独立发布的策略Web预览。

首次玩家不必先死亡或拿跨局档案。实际击杀3/7/12只怪解锁三册，每册选择一个天赋；可以先看地图、比较已知敌人，再回来决定，不增加抽卡货币或收费重抽。

- 第一、二册各在四种天赋中固定抽三种；第三册保留三种。固定种子与规则版本生成实际候选，不是只打乱原三项顺序。两册各有四种真实遗漏，最多16种候选池搭配，不宣传成无限构筑。
- 第一册新增“战术复盘”：目标与上一次实际击杀怪物同种时防御+4，首次击杀前没有加成。不叠层。选择先打同类还是转去拿资源，会影响下一战。
- 第二册新增“逆境蓄能”：存活击杀且实际损血至少40，战后恢复1专注，受上限限制。先扣当场技能，再结算返还；死亡不返。减伤可能让损血低于40，玩家要比较省生命与留专注，而不是默认每次开技能。
- 新册反馈在战报结束后出现，HUD持续显示进度。C中先预选、Enter确认、Esc稍后选择；展示当前层已知敌人及已到过第三层的存活宝库守卫，不泄露未探索楼层。远程预览不给虚构侧袭优势。
- 旧15及更早活动局保留原三项候选，不补抽。七层重训清选择但保留实际候选、击杀和上次击杀种类，不退款历史战斗收益。

schema16保存`talent_draft={version,offers}`及`last_kill_kind`。出生候选不可经普通保存或Undo改变；上次击杀种类可随真实Undo恢复，死亡不更新。

当前不新增传承技能点。后续候选方案是首次3/5/8层各1点、总共3点的有限配置容量，退役/胜利/死亡同标准、不鼓励反复死亡刷点；数值和技能20级饱和问题尚待试玩后决定，不能冒称已经实现。

## 初步平衡观察（不是完整平衡认证）

66条合法学者首章模拟比较了逆境蓄能、专注训练、哨卫知识，含实际取盾支路和按预览切装。逆境在多数前三层比训练少20左右生命，首章末往往多100–180生命，偏后期强选。确有‘卸盾从32损血变66，换来1专注再治愈80’的有限敌人收益；必须先存活，不能反复杀同一怪刷取。它符合资源规划，但39→40阈值和学者可提前治愈、生命无上限可能让逐战卸装变成繁琐作业。

本轮不为消灭组合而仓促削弱，也不声称全部英雄/词条/策略已平衡。观察真实试玩是否有意义地规划战斗，还是机械每战切装；若后者明显，再实测每层次数等有限触发方案。高等级治疗与跨局策略叠加尚未完成同规模合法路线比较。
