# 鼠标操作

- 悬停空地：显示安全路线和步数；不可达时显示原因。
- 点击空地：只走已清理的安全路线，不顺路拾取、开门或战斗。按键或再次点击可停止。
- 正交相邻物品：点击后走过去拾取，包括钥匙、宝物和药水。
- 正交相邻怪物：点击后战斗，使用与方向键相同的规则；安全模式拒绝致死战斗，风险模式仍需明确确认。
- 正交相邻商店、NPC或机关：点击直接打开对应选项，不自动购买、借贷或作出不可逆选择。
- 正交相邻门和楼梯：点击等同方向键，消耗钥匙或触发利息时保留确认。
- 远处和斜角对象：只查看，不会自动战斗、拾取或触发。先走到正交相邻位置再点。

本批通过完整规则测试及原生Godot实际点击试玩。浏览器Godot引擎实玩仍未在云端验证；网页发布成功不等于浏览器实玩认证。
