# 传承点：合法路线与长短期对照

本记录是玩法取舍的实验，不是全构筑平衡证明，也不是性能/CI 门禁。

## 可复现方法

在项目目录执行：

```sh
godot --headless --path . --script tools/audit_legacy_points_routes.gd
```

结构化结果：`docs/legacy-points-route-audit.jsonl`。引擎版本：Godot 4.6.3。

脚本先用 seed 1、原装无传承点的学者，从真实新局沿生成器首章见证路线走到 K，再明确继续远征，沿远征见证路线击败 Z。每一次移动、选天赋、治疗、继续章节均使用 World 的合法 action/step 并断言成功。之后调用合法 finish_run(victory) 和 Profile.settle，首次取得 3/5/8 里程碑，由此形成 3 点容量。**没有直接写入 HP、击杀、装备、地图、解锁或档案奖励。** 第一条 JSON 记录包含该先导旅程的收据。

随后实际创建 24 个新局：

- seed 1、23 × 护卫/游侠/学者 × 0/0、研习2/储备1、研习1/储备2，共18局；策略均选原装。
- seed 23 学者，合法抽到的 study/channel 策略分别搭配逆境蓄能 × 上述三种分配，共6局。
- 所有局完整走首章及远征见证路线。0/0是玩家明确不投入，并非没有获得容量。
- 未取可选装备、未调校词条、未购物、未用贷款、未走可选宝库。新局均合法选择英雄。
- 3杀选 keen_edge（若未提供则选实际首个候选）；普通组7杀选 trained_focus；极端组7杀选 adversity_charge；12杀选 battle_medic。这两个种子提供需要的合法候选。
- 学者在每一步前把现有专注治疗为HP；专注空时才用应急补给，再治疗。现系统无HP上限，所以不浪费治疗。
- 护卫/游侠仅当完整预览显示技能能降低下一战损血时投入技能；专注空时才为此使用补给。**这是一种局部启发式，不是为首领保留专注的全局最优策略。**
- “前三层”记录于进入4层的一刻；K后与Z后HP为真实终态数值，未把未花掉的专注再折算成HP。见证路径由相应生成器现场生成，不另造捷径。

均为seed23学者、7杀逆境蓄能；没有伪造天赋或额外点数。

**需要明确关注：** channel+逆境能在同一次高损血大怪胜利叠加回焦；学者可全部转为不封顶HP。它在0点时已达到2139HP，研习2/储备1把结果进一步推到2719HP，较0点增加580，较同seed原装策略+trained的同分配1548HP高1171。构筑收益很显著，不能宣传为已全面平衡。

但这不是无限循环：没有重复击杀、没有死亡回血，所有回焦来自有限合法幸存战斗；终局前必须活过实际损伤。本次没有为了逆境阈值反复换装备，也没有高等级词条，所以并未覆盖最强可能上界。

建议保留这种可解释的构筑成果，观察实际挑战是否消失，再决定是否调整同次回焦叠加或资源利用。不要仅因强组合存在立刻砍掉。新点数并非问题的唯一来源；现有channel+逆境和无HP上限已造成主要协同。
