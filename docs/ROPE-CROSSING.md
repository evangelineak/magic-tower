# 六层单次摆渡：保命、收益与回程的取舍

先做价值验证，再做有限内容。二层导流石阵被否决：现有水袋仅6格，把随机干区怪改成水区单入口守卫会改变资源预算与主线结构，不能为了增加机制硬塞。

本批采用六层一条单次绳。起落点以实际地图为准，是入口岸至守卫背侧，不把屏幕方向硬写成西到东。使用消耗1专注，落在已有空格，守卫仍在，不获得金币、击杀进度、战后恢复或楼层奖励；可以继续探索，也可以从背侧回击。绳断后不能再荡，回程需打通守卫或修桥。普通撤销仍整步恢复位置、专注和绳状态，不称为不可撤销选择。

这不是必选优势：护卫已有架盾在基线正面更省血；游侠原破甲与荡绳后背击可能同损；学者消耗的是治疗资源；高回焦构筑跳过怪也放弃击杀回焦和金币。80金币工程仍能处理三层桥与双向回访，绳仅六层一次。桥已建或守卫已死时不再误收专注。

只有指定起点、活跃旅程、活守卫、空落点与足够专注时才可确认。最后1专注会解除已准备的下场技能，确认前明确显示；余焦足够则保持备战。安全点击步行不会触发绳。地图格、门梯与生成资源预算不变。
