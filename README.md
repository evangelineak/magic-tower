# Magic Tower · 苍穹之钥

一个使用 **Godot 4.6 + Blender 4.3** 制作的原创魔塔玩法原型。受约束的种子随机、三英雄、可预判的战斗、回访宝库、机关芯取舍、金币贷款与最终 Boss。不是随机战斗：每一步都可以先算清楚再决定。

## 启动

1. 安装 Godot 4.6.x（标准版，无需 .NET）。
2. 在 Godot 项目管理器导入本目录的 `project.godot`，按 F6/F5 运行。
3. 或命令行：`godot --path .`；指定可复现的种子：`godot --path . -- --seed=42`。种子 0 是作者基线。

游戏界面暂为英文；中文本地化、音效和完整章节属于后续规划，不冒充已完成。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 / 战斗 / 拾取 / 上下楼 | WASD / 方向键，或点击相邻格 |
| 看怪物预计损血 | 鼠标悬停 |
| 怪物手册与规则 | H，关闭用 H / Esc / 点击 |
| 商店 / 机关 / 账本 | E，数字键或点击选择；Esc 取消 |
| 英雄 / 技能 / 装备 / 天赋 | C，Tab 切页，数字键或点击选择 |
| 撤销一步 | U，最多本次会话最近 100 步 |
| 保存 | 点击 SAVE 按钮，每步也自动保存 |
| 读取 | L / LOAD |
| 同种子重开 / 新种子开局 | R 两次 / N 两次，覆盖本版本自动存档 |

红宝石 +5 攻击，蓝宝石 +4 防御，药水 +100 生命。金钥匙开金门。金币可在第一层商人购买 60 金币的破甲武器（+12 攻击）。击败第五层的 Astral Regent 通关。没有真实货币、联网借贷或付费机制。

- 未装备或使用技能/天赋的基础公式，玩家先手：`损血 = (ceil(怪物生命 / (玩家攻击 - 怪物防御)) - 1) × max(0, 怪物攻击 - 玩家防御)`。
- 伏击敌人会先攻击；荆棘敌人在每次玩家攻击时反伤，含击杀一击。预览统一计算英雄、装备、技能和天赋，战后恢复不能救回致死战斗。
- 无法破防或会致死的战斗直接阻止，不消耗生命。
- 各楼层双向联通，拾取/开门状态保留；门是捷径，并非所有门都必须打开。
- 存档位于 Godot `user://journey-v3.json`，只在本机，不联网上传。启动新进程后按 L 继续。

## v0.3 可玩纵切：选择会留下遗憾

- 第三层的 Vault Colossus 守着可见宝库，通常需要后续成长或针对性构筑。可以先上楼成长，再回来争取 +10 攻击与 45 金币；不是主线必需品。
- 第二层唯一机关芯：修复一/三层电梯、在四层工坊获得 +8 防御、卖给一层商人换 35 金币。三选一，不可重复领取。放弃电梯仍能走普通楼梯回访。
- 商人提供一次 40 金币贷款：另收 2 金币手续费；首次进入四层、五层各按剩余本金收 10% 向上取整利息，最多两次。若一分钱不还，总应付 50。付款先费用、再利息、再本金。可在账本随时提前偿还当前可用金币。
- 探索步数、现实时间、上下楼回访不计息。进入计息节点前可以取消。到期欠款停止增长，之后新获得金币优先偿债；单局债务，不跨局。
- 四层碑文是五层静默钟秘密的线索。秘密取决于此前的机关芯决定，不要求每局收齐；不拿也能通关。
- 战斗显示双方、精确回合/单击伤害/总损血及技能/恢复反馈；可跳过，动画不会额外结算。仍非即时操作战斗。
- v3 独立存档文件，不覆盖旧 `journey.json` / `journey-v2.json`；旧版存档不迁移。撤销、读档一起恢复装备、债务、世界状态，不能保留收益却撤掉代价。

## v0.4：每局不同，但不是瞎随机

- 保留五层作者骨架、楼梯与重要地标，随机普通资源/敌人位置、少量支路；每层配额固定。接受一个种子前，模拟一条不依赖借贷、排水、技能或天赋的通关路线。最多尝试16次后回退基线；基线验证失败会阻止开始。不保证玩家的任何决策都能获胜。
- 同种子复现；保存的是当前完整世界，不是载入时重新随机。200种子已实际规则重放通关。
- 三英雄：护卫减伤、游侠破甲、学者治疗。技能消耗有限专注，只有首次到达新层才恢复，来回走不刷新。
- 击杀数3/7/12各选一项天赋，共9项，包括固定数值、低生命条件增伤、对特定敌人强化、无伤胜利恢复等。装备可选重盾或决斗装，均有代价。
- 水域是空间/资源选择：第二层排水打开遗物区，或者取120生命而放弃该区。不是元素克制倍率。
- 制图员任务要求从第三层带回调查样本，回访领取45金币或专注上限/恢复奖励，二选一。
- 第四层种子固定选择三种奇遇之一：守塔人付血/付钱强化；走私者交换钥匙/金币；决心之井以全部专注换攻击或付生命恢复专注。每处只能选择一次，也可永久拒绝。

- 九个原创 Blender 角色切图已用于地图、英雄卡、图鉴和战斗演出；源文件与可重建脚本同仓库提供。

这仍是五层玩法实验，不是完整商业游戏。尚未完成大规模房间拼接、长篇分支任务、装备词缀池/套装、多怪技能体系、音效、完整角色动画与跨平台发行。

## 工程与资产

- `scripts/world.gd`：独立规则模型、地图、存档校验。
- `scripts/generation.gd`：种子配额变化、保守可解性验证。
- `scripts/progression.gd`：英雄、装备、天赋和确定性战斗预览。
- `scripts/main.gd`：绘制、输入、撤销、保存及 UI。
- `assets/combat/characters.blend` 与九张 PNG：原创可编辑战斗角色与透明切图。
- `tools/build_characters.py`：运行 `blender -b -P tools/build_characters.py` 可重建九张角色图。
- `assets/tower.blend`：原创可编辑 Blender 魔塔场景。
- `assets/tower.glb`：导出 3D 模型，供后续 3D 展示使用；当前战棋棋盘是 2D。
- `assets/tower.png`：Blender 实际渲染并在游戏左侧使用。
- `tools/build_assets.py`：可复现生成器，运行 `blender -b -P tools/build_assets.py`。
- `docs/PLAN.md`：初版规划；`docs/ROADMAP.md`：当前实现与剩余；`docs/VERIFICATION.md`：分批验收。

Godot 已关闭 `.blend` 自动导入，避免运行项目必须安装 Blender。保留源文件，实际用 PNG；GLB 可直接在 Godot 中查看。

## 测试

全部检查：`bash tools/test_all.sh`。GitHub工作分支配置同套只读验证流水线，Godot下载使用官方发行文件及SHA-256校验；具体CI状态以当前提交为准。

```sh
godot --headless --path . --editor --import --quit
godot --headless --path . --script tests/test_world.gd
godot --headless --path . --script tests/test_main.gd
godot --headless --path . --script tests/test_choices.gd
godot --headless --path . --script tests/test_adventure.gd
godot --headless --path . --script tests/test_progression.gd
godot --headless --path . --script tests/test_generation.gd
godot --headless --path . --script tests/test_events.gd
godot --headless --path . --script tests/test_adversarial.gd
godot --headless --path . --quit-after 30
```

自动测试覆盖墙、锁门、钥匙消耗、确定性损血、无法破防、致死保护、JSON 往返、坏存档拒绝，以及由真实规则执行的五层不借贷完整通关及后期回访宝库路径。最新验证见 `docs/VERIFICATION.md`。

原型不依赖网络服务、第三方素材、密钥或付费 API。尚未包含各平台独立可执行程序；源码在 Godot 中运行。
