# Magic Tower · 苍穹之钥

一个使用 **Godot 4.6 + Blender 4.3** 制作的原创魔塔玩法原型。受约束的种子随机、三英雄、可预判的战斗、回访宝库、机关芯取舍、金币贷款与最终 Boss。不是随机战斗：每一步都可以先算清楚再决定。

公开网页试玩（与开发分支独立发布，版本以网页 BUILD.txt 为准）：https://evangelineak.github.io/magic-tower/ 。需要支持 WebGL2 的桌面浏览器；首次加载约40MB。网页与开发分支独立发布，浏览器存档不和桌面版同步，刷新后按L读取。当前云浏览器图形限制使Web内实玩与刷新读档尚未验收。

## 先选择玩法模式

主页上方点击 **新版无尽远征 / F3** 进入持续更新的无尽模式。15×15地图、五类双路线布局、独立旅程存档、营地战术、运输与信使任务、种子遭遇、一次性道具与单槽持久装备都在这个入口。新怪物包括逐击反伤的棘甲守卫和有条件回血的回春祭司，战前可查看精确损耗。B战术、R遭遇、I道具/装备、Q信使、T沿已清空的安全路线回营、H帮助；入口楼梯角徽章可比较并付费激活本层震击/寂静铭文，改变交手时序且有代价，详见 [v13](docs/ENDLESS-V13.md)。已有旅程保持创建时的规则，N确认新开局才体验新版。排名仅在本设备，不是全球榜。

下面的五层首章、三英雄及快捷键表属于**经典模式**，不是无尽模式的功能清单。两模式不互相覆盖存档，也尚未合并为一套完整玩法。

## 启动

1. 安装 Godot 4.6.x（标准版，无需 .NET）。
2. 在 Godot 项目管理器导入本目录的 `project.godot`，按 F6/F5 运行。
3. 或命令行，首次克隆/更新资源先运行 `godot --headless --path . --editor --import --quit`，再运行 `godot --path .`；指定可复现的种子：`godot --path . -- --seed=42`。种子 0 是作者基线。

游戏默认简体中文，F2可切换英文；语言不影响规则和存档。当前包含五层首章和可主动继续的三层远征，仍是内容原型。

红宝石 +5 攻击，蓝宝石 +4 防御，药水 +70 生命，初始生命 280。普通金门耗1钥匙，双锁门耗2钥匙，花费前可取消。金币可在第一层商人购买 60 金币的破甲武器（+12 攻击）。击败第五层的 Astral Regent 获得首章胜利，可保留胜利或主动继续三层远征。没有真实货币、联网借贷或付费机制。

- 未装备或使用技能/天赋的基础公式，玩家先手：`损血 = (ceil(怪物生命 / (玩家攻击 - 怪物防御)) - 1) × max(0, 怪物攻击 - 玩家防御)`。
- 伏击敌人会先攻击；荆棘敌人在每次玩家攻击时反伤，含击杀一击。预览统一计算英雄、装备、技能和天赋，战后恢复不能救回致死战斗。
- 无法破防直接阻止；默认安全模式也阻止致死战斗。明确选择风险模式的新局，可再次确认致死挑战，真实死亡后结束本局，不能用战后恢复救回。
- 新局相邻楼层的上下梯同坐标对应，拾取/开门状态保留。钥匙门封住真实奖励区域，不必打开所有门；旧档保留旧地图和旧传送规则。
- 新版 Session 使用本地 `user://journeys-v1/` 原子容器；网页使用独立 IndexedDB `magic-tower-journeys-v1`。启动读取当前旅程，L 重新取得写入权并读取实际保存状态，F5 重试待确认保存。旧 `journey-v4.json` 原样保留但不自动导入；本批请开新局。数据不上传服务器。

## v0.3 可玩纵切：选择会留下遗憾

- 第三层的 Vault Colossus 守着可见宝库，通常需要后续成长或针对性构筑。可以先上楼成长，再回来争取 +10 攻击与 45 金币；不是主线必需品。
- 第二层唯一机关芯：修复一/三层电梯、在四层工坊获得 +8 防御、卖给一层商人换 35 金币。三选一，不可重复领取。放弃电梯仍能走普通楼梯回访。
- 商人提供一次 40 金币贷款：另收 2 金币手续费；首次进入四层、五层各按剩余本金收 10% 向上取整利息，最多两次。若一分钱不还，总应付 50。付款先费用、再利息、再本金。可在账本随时提前偿还当前可用金币。
- 探索步数、现实时间、上下楼回访不计息。进入计息节点前可以取消。到期欠款停止增长，之后新获得金币优先偿债；单局债务，不跨局。
- 旧塔校准在一层商人、二层阀门、四层碑文各留一条线索，五层静默钟需要电梯供能；不拿也能通关。v0.10扩展见下。
- 战斗显示双方、精确回合/单击伤害/总损血及技能/恢复反馈；可跳过，动画不会额外结算。仍非即时操作战斗。
- v4 独立存档文件，不覆盖旧 `journey.json` / `journey-v2.json` / `journey-v3.json`；旧版存档不迁移。撤销、读档一起恢复装备、债务、世界状态，不能保留收益却撤掉代价。

## v0.4：每局不同，但不是瞎随机

- 保留五层作者骨架、楼梯与重要地标，随机普通资源/敌人位置与有限房间模板（v0.7新增）；每层配额固定。接受一个种子前，模拟一条不依赖借贷、排水、技能或天赋的通关路线。最多尝试16次后回退基线；基线验证失败会阻止开始。不保证玩家的任何决策都能获胜。
- 同种子复现；保存的是当前完整世界，不是载入时重新随机。200种子已实际规则重放通关。
- 三英雄：护卫减伤、游侠破甲、学者治疗。技能消耗有限专注，只有首次到达新层才恢复，来回走不刷新。
- 击杀数3/7/12各选一项天赋，共9项，包括固定数值、低生命条件增伤、对特定敌人强化、无伤胜利恢复等。装备可选重盾或决斗装，均有代价。
- 水域是空间/资源选择：第二层排水打开遗物区，或者取120生命；v0.7可用调查样本换桥再回访，但因此放弃制图员奖励。不是元素克制倍率。
- 制图员任务要求从第三层带回调查样本，回访领取45金币或专注上限/恢复奖励，二选一，或将样本交给四层工匠修桥。
- 第四层种子固定选择三种奇遇之一：守塔人付血/付钱强化；走私者交换钥匙/金币；决心之井以全部专注换攻击或付生命恢复专注。每处只能选择一次，也可永久拒绝。

- 十三个原创 Blender 角色切图已用于地图、英雄卡、图鉴和战斗演出；源文件与可重建脚本同仓库提供。

这仍是两章八层玩法实验，不是完整商业游戏。尚未完成大规模房间拼接、长篇分支任务、装备词缀池/套装、多怪技能体系、完整角色动画与正式发行。

## v0.6：不是所有好东西都能拿完

- 初始280生命、药水70；中途伏击和荆棘敌人加强。200种子仍有不借贷、不用技能、不消费钥匙的主线通路，但错误选择不兜底。
- 护卫技能减免总伤害35%，强化45%（减免量向下取整），适合重战；学者提供稳定80/100治疗；游侠通过破甲突破高防，三者不是同一种加数。
- 五层各一把金钥匙，共五把；第1/3/4层三处双锁奖励笼共需六把，分别提供60金币、5攻击、140生命与1专注。普通捷径也用这批钥匙。默认不能全拿；特定奇遇能补钥匙，但要付机会成本。
- J旅途日志记住已发现的线索、未领宝物、取舍与债务。开门前确认花费，取消不扣钥匙，撤销恢复完整状态。

数值调整依据见 `docs/BALANCE.md`，不是只凭感觉削弱玩家。

## v0.7：空间改变与任务联动

- 每层两块普通区域，各有四种墙体/通路模板；不改楼梯、水域、奖励笼和宝库。验证关键物可达、奖励必须经过对应门/守卫、水区不能绕过，再实际模拟通关。种子0保留作者原图。模板版本升级会改变同种子的新开局；旧存档保存完整地图，加载不重生成。
- 三层调查样本可以回一层换钱/专注，或交四层工匠修二层水桥。先喝泉再造桥、先造桥再喝泉都可以；已排水则不浪费样本造桥。桥不消耗唯一机关芯。
- 六种原创程序合成音效，M可静音；音效只跟随已成功操作，不参与战斗计算。
- 提供Linux/Windows导出预设与本地构建脚本。Linux可独立运行；Windows交叉导出不等于已在Windows运行验证。细节见 `docs/EXPORT.md`。

## v0.8：装备改变交手顺序

- 重盾仍为-4攻击/+6防御，额外挡住第一记敌方攻击（先制优先）；不挡荆棘，不能把未受伤的一击变成回血。
- 决斗装仍为+6攻击/-3防御，另忽略8敌防，但会招来一次额外开局反击，即使随后一击击杀也要付代价。高甲长战可能赚，低甲短战可能亏，可换回均衡装。
- 第四层新增黄铜重装守卫，每第三次反击造成双倍防御后伤害；决斗佯攻计入反击，先制不计。图鉴、悬停和战斗结算显示原因，不靠隐藏随机伤害。
- 先合计各伤害分项，再扣装备挡伤、护卫百分比、Unbroken固定减伤，最后判定存活及战后恢复。总减伤已经包含盾挡，不重复扣。
- 旧v4存档可继续读，装备归属不变，但按新战斗规则重新预告。升级后请先看预览，不沿用旧版本损血记忆。

## v0.9：中文界面与独立字体

- 默认中文，F2在任何面板切换中英，不消耗行动，不改变战斗、世界或存档。
- 固定文案精确翻译；带数值的提示按显式模板解析，保留数值、正负号和百分比。英雄、装备、天赋、图鉴、事件、借贷、旅途日志均使用同一显示层。
- 打包MagicTowerCJK字体子集，不依赖玩家电脑安装中文字体。字形来自Noto Sans CJK，并非原创；字体本身遵循SIL OFL 1.1，完整许可随源码及桌面包提供。
- 新中文文案后执行 `python tools/build_font.py`，检查用 `python tools/build_font.py --check`。子集只覆盖游戏文本，不声称支持任意用户输入。

## v0.10：旧塔校准，回来补上遗憾

- 第一层商人的契约、第二层阀门、第四层碑文给出三条顺序约束。四符号由种子决定，有24种排列；三条线索各有作用，合起来唯一解，不靠颜色或站外知识。
- 第五层钟台只有在集齐线索、修复电梯供能后才能校准。拿机关芯之前就会告知条件；锻造或出售机关芯会放弃这条支线。
- 四个输入槽允许退格、清空；输错仅清空，不扣生命、金币、专注，也不计息。线索一直可以回访，泉水、排水和样本分支不会删除线索。
- 完成后二选一：80生命＋1钥匙，或固定50金币账券。账券先抵当前债务，余款入袋，提前还款不吃亏，也不恢复再次借贷资格。
- 额外钥匙是刻意设计的晚期补救：可以返回旧楼层争取曾经舍弃的奖励，前提是此前没有把钥匙全花在捷径上。仍不保证收齐一切。
- 存档内部升级为schema5，仍沿用 `journey-v4.json` 路径。成功读取schema4时先保存一次 `.pre-schema5.json` 原文件备份（不覆盖已有备份）；旧版本已经领过秘密奖励的记录不会再领新奖励。

## v0.11：整层路线不再只是局部开墙

- 非零种子每层选择环廊、双庭或脊道三种完整骨架：绕行、枢纽与折返各有区别，不是简单镜像。仍保留关键物、门、宝库和水区的设计位置。
- 普通敌物按每层预算重新摆放。干区/湿区分池且保留种类：水后的攻击宝石不白送主路，默认钥匙不随机藏到水后。
- 即使打开普通门，也不能绕过双锁、宝库守卫或水域；关键M/O/N可回访。所有接受的地图仍提供真实规则通关见证，错误选择不兜底。
- 新骨架覆盖五层、200种子真实回放。它是有限骨架生成，不是无限章节；详细约束见 `docs/GENERATION.md`。分享种子请同时说明游戏版本，旧存档不重抽地图。
- 测试脚本现在先导入资源，避免刚克隆或更新字体时使用缺失/过期的导入缓存。

## 工程与资产

- `scripts/world.gd`：独立规则模型、地图、存档校验。
- `scripts/generation.gd`：种子配额变化、保守可解性验证。
- `scripts/progression.gd`：英雄、装备、天赋和确定性战斗预览。
- `scripts/main.gd`：绘制、输入、撤销、保存及 UI。
- `assets/combat/characters.blend` 与十张 PNG：原创可编辑战斗角色与透明切图。
- `tools/build_characters.py`：单角色增量可用 `-- --only juggernaut`；运行 `blender -b -P tools/build_characters.py` 可重建十张角色图。
- `assets/tower.blend`：原创可编辑 Blender 魔塔场景。
- `assets/tower.glb`：导出 3D 模型，供后续 3D 展示使用；当前战棋棋盘是 2D。
- `assets/tower.png`：Blender 实际渲染并在游戏左侧使用。
- `tools/build_assets.py`：可复现生成器，运行 `blender -b -P tools/build_assets.py`。
- `docs/PLAN.md`：初版规划；`docs/ROADMAP.md`：当前实现与剩余；`docs/VERIFICATION.md`：分批验收。

Godot 已关闭 `.blend` 自动导入，避免运行项目必须安装 Blender。保留源文件，实际用 PNG；GLB 可直接在 Godot 中查看。

## v0.16：空间机关与攻击节奏

- 新开启的远征七层有一台只能锁定一次的卷扬机：北侧救援捷径，或重击锤装备库。选择库房仍可成长后正面打狱卒救人；选择捷径会永久放弃锤。决定前显示后果并再次确认，也可以暂不决定。

## 开局策略抽选（当前开发批次，网页未更新）
